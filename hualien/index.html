瀏覽器就能玩的火車駕駛模擬

從駕駛室的 3D 視角操作主控制器與煞車，把車頭停在月台的停車位置標上。免安裝，手機也能玩。

  • 台灣花東線（花蓮 → 吉安 → 志學 → 平和 → 壽豐）：區間車穿過稻田，西邊就是中央山脈。附新手教學。
  • 阿里山林業鐵路祝山線（阿里山 → 對高岳 → 祝山）：762 mm 窄軌登山鐵道，最陡 62‰，搭日出列車看雲海日出。
  • 台北捷運淡水信義線（北投 → 關渡 → 紅樹林 → 淡水）：雙線區間，看關渡大橋、淡水河紅樹林與觀音山。
  • 京急本線（品川 → 北品川 → 新馬場 → 青物橫丁 → 鮫洲 → 立會川）：紅色電車、八ツ山橋、北品川的平交道，在鮫洲等快特超車。
  • JR 京葉線（新木場 → 葛西臨海公園 → 舞濱 → 新浦安 → 市川鹽濱）：東京灣邊的高架雙線，看得到摩天輪和海。
  • 日本江之電（稻村崎 → 七里濱 → 鎌倉高校前 → 腰越 → 江之島）：相模灣、富士山、江之島、鎌倉高校前平交道，以及腰越到江之島的路面電車區間。

可以選晴天、黃昏、夜間或雨天，有行車音效、車內廣播與成就徽章。
