# 花東線駕駛室・阿里山小火車・台北捷運・江之電

3D 駕駛室視角的台灣火車駕駛遊戲，比停車精準度、準點與遵守號誌速限。標題畫面可以選路線：

- **花東線**：區間車從花蓮開到壽豐，沿途停靠吉安、志學、平和。
- **台北捷運淡水信義線**：北投往淡水，雙線區間、第三軌供電，對向列車不斷從右邊開過。沿途看得到關渡平原、紅色的關渡大橋、淡水河紅樹林、觀音山和大屯山，車站是捷運風格的紅色站名牌與 LED 看板。
- **JR 京葉線（日本）**：新木場往市川鹽濱，東京灣邊的高架雙線，跨過荒川與舊江戶川；右邊是海、葛西臨海公園的摩天輪（夜間點燈）、舞濱的度假飯店與新浦安的高樓，遠方是幕張天際線。列車開往蘇我，你的班在市川鹽濱換手。
- **江之電（日本）**：從稻村崎往江之島，左手邊是相模灣，前方看得到江之島和富士山；途經七里濱、鎌倉高校前（《灌籃高手》的平交道）、腰越，腰越之後是和汽車共用道路的路面併用軌道。到站小知識連到江之電官網與日本觀光網站。
- **阿里山祝山線**：柴油機車牽引的登山小火車，從阿里山（海拔 2,216 m）爬到全台最高的祝山車站（2,451 m），途經對高岳。762 mm 窄軌、最陡 62‰、急彎時輪緣會尖叫。選「日出列車」會在清晨發車，天色一路從星空變成雲海日出。

遊戲內的距離與坡度為示意，比實際路線短。

支援**中文、English、日本語**：標題畫面右上角切換，或用網址 `?lang=zh`、`?lang=en`、`?lang=ja`。第一次進站會依瀏覽器語言自動選擇。

線上遊玩：https://train.sectools.tw/

## 新手教學

標題畫面按「🔰 新手教學」，教練會一步步帶你從花蓮開到吉安：起步、看限速、等車尾通過解除標、平交道鳴笛、進站煞車、微調停車、開門。每出現新提示時間會先停住，對應的儀表或按鈕會閃框提示。

## 難度、車種與紀念章

- **🔰 新手**：時刻表寬鬆、扣分減半、不會空轉；該煞車時提醒，誤差尺上的綠色三角形是預計停車位置。每條路線第一次開會自動帶新手教學（可跳過）。
- **🎯 專業**：實際時刻表、扣分加重，ATP 超速 3 km/h 就介入，停車誤差尺只在最後 20 m 出現。
- **解鎖車種**：花東線 A 評價 → EMU900；阿里山「祝山看日出」→ 蒸汽機車 SL-31（有排煙、汽笛與排氣聲）；專業模式開完江之電 → 300 形。
- **車站紀念章**：停車誤差 3 m 內蓋到該站的紀念章，三條路線共 13 個。
- **車內廣播**：歡迎、即將到站與開門方向、誤點致歉、海拔、行車調度無線電；臺鐵與林鐵播國語與英語，江之電播日語與英語，同步顯示字幕。

## 介面與體驗

- 主選單分成「出發／收藏／設定」三個分頁，背景是正在路線上行駛的 3D 畫面；開始駕駛按鈕固定在面板底部。
- 載入畫面會顯示路線名稱與駕駛小技巧。
- 停車後畫面中央跳出評價（PERFECT 完美、GREAT 優秀…），緊急煞車時畫面震動，結算分數會跳動，拿到 A／S 評價會灑彩帶。
- 可以安裝成 App（PWA）：手機「加到主畫面」後以全螢幕開啟，也能離線遊玩；駕駛時有全螢幕按鈕。

## 在地地標（位置為示意）

- 花東線：稻田裡的白鷺鷥、路邊的土地公廟、吉安附近的日式佛寺（慶修院）、志學一帶的大學校園、壽豐附近的廟。
- 阿里山：祝山觀日平台與等日出的人群。
- 江之電：坡上的鎌倉高校校舍、平交道旁拍照的遊客、七里濱海上的衝浪客、江之島入口的青銅鳥居。
- 淡水線：河邊的關渡宮、關渡濕地的白鷺鷥、淡水河上的船。

遊戲裡的站距、速限與坡度為了好玩有簡化，車站順序、軌距、供電方式和地標方位則照真實路線設計。

## 畫面風格

標題畫面可以切換「🧱 方塊」（預設）或「🌄 寫實」。方塊風格是像積木一樣的世界：像素材質的草地與碎石、方塊樹與方塊雲、一層層的方塊山（富士山、玉山、觀音山），阿里山的山坡做成梯田狀。

## 會車與風景

- 單線路線在側線會車：花東線志學、阿里山對高岳、江之電七里濱與腰越，對向車在側線等你進站後出發，錯車時有風切聲與鳴笛。
- 月台有長椅、時鐘、LED 列車資訊看板，江之電還有自動販賣機；軌道旁有花草（江之電是紫陽花），天空有鳥群、層次雲與太陽光暈，阿里山車站附近會飄櫻花瓣。

## 真實感

- **行車音效**：輪軌滾動聲與風切隨速度變化、每 25 m 鋼軌接縫的「喀噠—喀噠」、加速時的馬達聲、煞車排氣與緊急煞車洩氣、低速煞車摩擦聲、平交道警鈴（越近越大聲）、關門前蜂鳴、ATP 警報。第一次點擊或按鍵後啟動，可在標題畫面關閉。
- **天氣與時段**：晴天早晨、黃昏、夜間（頭燈、月台燈、星空、亮燈的車站）、雨天（雨絲、擋風玻璃雨滴與雨刷）。發車時刻也會跟著改變。
- **雨天濕軌**：煞車力約少 15%，低速大檔位容易空轉，儀表會亮「空轉」。
- **坡度**：沿線有上下坡，右側有坡度標，「前方」會預告坡度變化。上坡加速慢、下坡放 N 也會加速。
- **儀表**：新增煞車缸壓力（BC kPa）與目前坡度；駕駛視角在經過鋼軌接縫時會輕微震動。

## 執行

不需要安裝或編譯，直接用瀏覽器打開 `index.html` 就能玩（需要網路，用來載入 three.js 與字型）。

如果瀏覽器擋住本機檔案，可以在這個資料夾開一個簡單的本機伺服器：

```bash
npx serve .
# 或
python3 -m http.server 8000
```

然後打開 http://localhost:8000 。

## 專案結構

```
index.html        頁面結構（標題列、駕駛視窗、路線條、駕駛台、彈出視窗）
css/style.css     樣式（駕駛台深色主題、手機版排版）
js/data.js        路線資料：車站位置、時刻、速限區、曲線、平交道、號誌位置，以及共用小工具
js/game.js        遊戲邏輯：狀態、列車物理、ATP、號誌、進站計分、操作說明、按鍵與按鈕
js/extras.js      成就、最佳紀錄、車內廣播與開門音、旅客評語、分享成績
js/tutorial.js    新手教學的步驟與教練提示框
js/help.js        操作說明的英文與日文版
js/audio.js       行車音效（Web Audio 合成，不需要音檔）
js/render3d.js    three.js 3D 場景：軌道、景物、山脈、車站、號誌、平交道與駕駛室視角
js/hud.js         速度表與駕駛台儀表讀數
js/main.js        主迴圈與啟動
```

各檔案是一般的 `<script>`，依 `index.html` 裡的順序載入並共用全域變數，所以順序不能調換。

## 常改的地方

- **車站與時刻**：`js/data.js` 的 `STATIONS`。`pos` 是停車位置（公尺），`leg` 是從上一站出發的預定行駛秒數。
- **坡度**：`js/data.js` 的 `GRADES`，`g` 是千分比（正值上坡）。
- **路線**：`js/data.js` 的 `ROUTES`（車站、速限、彎道、坡度、列車性能）。
- **天氣與時段**：`js/data.js` 的 `ENVS`（名稱與發車時刻）和 `js/render3d.js` 的 `LOOKS`（天空、霧、光線顏色）。
- **速限**：`js/data.js` 的 `LIMITS`，`s`／`e` 是起訖位置，`v` 是 km/h。
- **彎道**：`js/data.js` 的 `CURVES`，`k` 是曲率（1/半徑），正值往右彎。
- **列車性能**：`js/game.js` 的 `step()`，包含加速度、煞車減速度與行車阻力。
- **計分**：`js/game.js` 的 `action()`（停車與準點）和 `penal()` 的呼叫處（扣分）。
