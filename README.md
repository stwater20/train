# 花東線駕駛室

3D 駕駛室視角的區間車駕駛遊戲。從花蓮開到壽豐，沿途停靠吉安、志學、平和，比停車精準度、準點與遵守號誌速限。

線上遊玩：https://stwater20.github.io/train/

## 新手教學

標題畫面按「🔰 新手教學」，教練會一步步帶你從花蓮開到吉安：起步、看限速、等車尾通過解除標、平交道鳴笛、進站煞車、微調停車、開門。每出現新提示時間會先停住，對應的儀表或按鈕會閃框提示。

## 其他好玩的

- **成就徽章**：完美停車、全站準點、零扣分、三個平交道都鳴笛、S 級……也有「紅燈戰士」這種不太光彩的。
- **最佳紀錄**：記住你的最高分與開過幾班車（存在瀏覽器裡）。
- **車內廣播**：瀏覽器語音播報「下一站，吉安」，到站有開門提示音，可在標題畫面關掉。
- **旅客評語**：下車的旅客會依你的駕駛表現留下一句話。
- **分享成績**：一鍵分享或複製各站停車誤差。

## 執行

不需要安裝或編譯，直接用瀏覽器打開 `index.html` 就能玩（需要網路，用來載入 three.js 與字型）。

如果瀏覽器擋住本機檔案，可以在這個資料夾開一個簡單的本機伺服器：

```bash
npx serve .
# 或
python3 -m http.server 8000
```

然後打開 http://localhost:8000 。

## 專案結構

```
index.html        頁面結構（標題列、駕駛視窗、路線條、駕駛台、彈出視窗）
css/style.css     樣式（駕駛台深色主題、手機版排版）
js/data.js        路線資料：車站位置、時刻、速限區、曲線、平交道、號誌位置，以及共用小工具
js/game.js        遊戲邏輯：狀態、列車物理、ATP、號誌、進站計分、操作說明、按鍵與按鈕
js/extras.js      成就、最佳紀錄、車內廣播與開門音、旅客評語、分享成績
js/tutorial.js    新手教學的步驟與教練提示框
js/render3d.js    three.js 3D 場景：軌道、景物、山脈、車站、號誌、平交道與駕駛室視角
js/hud.js         速度表與駕駛台儀表讀數
js/main.js        主迴圈與啟動
```

各檔案是一般的 `<script>`，依 `index.html` 裡的順序載入並共用全域變數，所以順序不能調換。

## 常改的地方

- **車站與時刻**：`js/data.js` 的 `STATIONS`。`pos` 是停車位置（公尺），`leg` 是從上一站出發的預定行駛秒數。
- **速限**：`js/data.js` 的 `LIMITS`，`s`／`e` 是起訖位置，`v` 是 km/h。
- **彎道**：`js/data.js` 的 `CURVES`，`k` 是曲率（1/半徑），正值往右彎。
- **列車性能**：`js/game.js` 的 `step()`，包含加速度、煞車減速度與行車阻力。
- **計分**：`js/game.js` 的 `action()`（停車與準點）和 `penal()` 的呼叫處（扣分）。

## 操作

| 動作 | 鍵盤 |
| --- | --- |
| 往動力推一格 | W / ↑ |
| 往煞車拉一格 | S / ↓ |
| 回中立 | N |
| 緊急煞車 | E |
| 停妥後開門 | 空白鍵 |
| 鳴笛 | H |
| 暫停 | P |
| 操作說明 | ? |

完整規則請看遊戲內的「操作說明」。
